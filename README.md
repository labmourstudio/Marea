# Marea

Marea is a bilingual Vietnamese–English creative social network concept for writers, artists, game designers and worldbuilders.

Live website: https://labmourstudio.github.io/Marea/

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Included in this prototype

- Login and three-step profile onboarding
- Vietnamese/English interface switcher
- Responsive social feed with filters and interactions
- Friends, Worlds, Projects, Learn, Profile and Studio experiences
- Story and game character builder previews
- Private/public content workflow cues
- Client-side admin route guard demo at `/admin`

This repository is a frontend prototype. Production authentication, server-side authorization, database persistence, file uploads, moderation, MFA/passkeys and audit logging require a backend implementation.
